## How the agent builds this kind of link

Page builder site. Sign up, create a site or page from any template, add a text or paragraph block, write a short
relevant paragraph and insert the link as a hyperlink on the anchor text (or the HTML block the guide shows), then
publish. Verify on the published page's public URL, not the editor.
Pitfalls: unpublished drafts are not live; some builders put new sites behind a "coming soon" page until you turn it off.
