What the agent does

Plans

Picks sites by authority and effort, balances the dofollow share, and assigns anchor text by the ratio you set: exact, partial, branded, naked, generic.

Builds

Login-free sites run on scripted playbooks. Account-based sites run on the model-driven browser executor: it reads the site's method and the page each turn, signs up, fills the profile or writes the post, and places the link, with a proof screenshot.

Verifies

Opens the live page and checks the hyperlink, the anchor text and whether it is nofollow before a link counts. Every result is logged with its proof, and a re-check later shows which links still stand.

Gates are handled in the chat, not skipped

When a site asks for a captcha, an email code, a phone code, a social login or a payment, the agent stops and asks you in the same conversation. You clear it in the browser window it opens, connect a service once (a captcha solver, your inbox over IMAP, an SMS number) so it handles the next one itself, paste the code, or skip the site. Then the build continues where it stopped.
