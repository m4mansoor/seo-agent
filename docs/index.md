# SEO Agent

An open-source SEO agent for link building. It runs inside the AI assistant you already use, as an MCP server, and does the part of SEO that has always been manual: finding sites that give links, following each site's method, placing the link, and checking it went live.

```bash
pip install seo-agent
claude mcp add seo-agent -- seo-agent
```

## What you get for free

- 50 backlink sites with Domain Authority 37 to 69, referring domains, and a method for each.
- The playbooks that teach your assistant how to place a profile link, an article link, a bookmark, a forum post or a web 2.0 page.
- One prompt, `build_backlink`, that packages a site's method, your anchor and the verification rules.

## What the full library adds

1,245 sites, 1,138 verified reachable, 900 dofollow, 117 at DA 90 or higher, every domain with referring domains, backlinks, spam score and organic traffic. Plus the campaign planner, automatic building on login-free sites with proof screenshots, link verification and the results log. Available with a free API key when the hosted service opens.
