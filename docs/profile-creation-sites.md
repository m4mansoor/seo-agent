## How the agent builds this kind of link

Profile website field. Create the account, complete any onboarding, then open profile settings or "edit profile".
Put the target URL in the field the guide names (Website, Homepage, URL, Links, About, Bio). If the field is a free-text
bio or about box, write one or two natural sentences and include the full URL (some sites auto-link it) or an HTML/BBCode
link if the guide shows that format. Save, then open the PUBLIC profile page (not the edit page) to verify.
Pitfalls: some profiles are private until an avatar or first post exists; some hide the website field until email is
verified; a few strip links from bios but keep the dedicated Website field.
