## How the agent builds this kind of link

Bookmark or link submission. Find "Add link", "Submit", "Add URL" or "Post". Fill URL, title (use the anchor text or a
descriptive title containing it), description (one or two sentences), category and tags. Submit. Verify on the new
bookmark's page or the listing that shows it.
Pitfalls: many of these are Pligg or Scuttle clones with a captcha at submit; if it appears, report manual. Some show the
link only after a moderator approves, report unverified with the submission page URL.
