## How the agent builds this kind of link

Forum post or reply. Register, verify email if asked, then either open the thread the guide names or start a topic in a
relevant board. Write a useful reply or topic of a few sentences and include the link once, on the anchor text if the
editor supports links or as the bare URL. Verify on the thread page.
Pitfalls: many forums block links for new members until a few posts exist; if the link is stripped, report manual with
that note. Do not spam multiple threads.
